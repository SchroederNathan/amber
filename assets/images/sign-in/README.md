# Provider logos

- `google-g.png` is Google's official full-color G, reused from Speech Companion. Its original source is https://developers.google.com/static/identity/images/g-logo.png. Keep the original colors. Usage guidance: https://developers.google.com/identity/branding-guidelines.
- `apple.svg` uses the unchanged glyph path from Apple's `Logo - SIWA - Left-aligned - Black - Large.svg`, downloaded from https://devimages-cdn.apple.com/design/resources/download/Logo-Sign-in-with-Apple.dmg on 2026-09-23. The SVG omits the sample button background and fits the glyph in a 24-point icon box. The bundled artwork license is in `APPLE-ARTWORK-LICENSE.txt`. Source: https://developer.apple.com/design/resources/.

Both assets are bundled locally. Expo Image keeps Google in color and gives the Apple mark the sign-in button's contrasting foreground color.
